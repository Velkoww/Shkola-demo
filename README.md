# Школа по езици „Даниела Гоцева“ – демо сайт

Статичен демо сайт (една страница) за школа по езици в ж.к. Обеля 1, София.

## Cloudflare
- **Workers** (Import a repository): без build команда – `wrangler.jsonc` качва статичните файлове.
- **Pages** (алтернатива): Framework preset *None*, Build command празно, Output directory `/`.

## За уточняване с клиента
- Работно време (в Maps пише само „до 18:00“), цени, възрастови групи, математика (на табелата пише „Школа по езици и математика“).
- Формата за запитване е демо – да се свърже с Web3Forms.
- Снимки: използвани са само снимки без лица на деца; за останалите е нужно съгласие на родителите.
